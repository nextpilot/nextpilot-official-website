# NextPilot Documentation

> NextPilot is an open-source advanced autopilot (flight controller) developed in China, built on RT-Thread and PX4, supporting multirotor, fixed-wing and VTOL aircraft for education, research and industry. This file provides a curated navigation index of the site's core content for large language models (LLMs); the full Markdown source dump of every page is available at llms-full-en.txt below.
