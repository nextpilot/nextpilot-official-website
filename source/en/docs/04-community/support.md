# Technical Support

If you run into any problem while using NextPilot, please first post on [GitHub Discussions](https://github.com/nextpilot/nextpilot-flight-control/discussions) (because it may be caused by flight controller configuration).

Following the guidance of the development team, if it is determined to be a code issue, please report it on [GitHub Issues](https://github.com/nextpilot/nextpilot-flight-control/issues). If possible, please provide [flight logs](https://logs.px4.io) and other information.

## Reporting Issues

The core development team and community members are active on the following channels, where you can get help.

Discussion forum: <https://github.com/nextpilot/nextpilot-flight-control/discussions>

Issue tracker: <https://github.com/nextpilot/nextpilot-flight-control/issues>

Submit code: <https://github.com/nextpilot/nextpilot-flight-control/pulls>

## Troubleshooting

If you are not sure what the problem is and need help diagnosing it, we recommend following these steps:

- Upload the flight log to [Flight Log Review](https://logs.px4.io/) and read the analysis report.
- Search [GitHub Discussions](https://github.com/nextpilot/nextpilot-flight-control/discussions) to see whether a similar issue already exists; if not, open a discussion. If the problem turns out to be caused by a bug, the development team may ask you to file an Issue.

- File an issue at [GitHub Issues](https://github.com/nextpilot/nextpilot-flight-control/issues/) containing a detailed description of the problem (enough to reproduce it) and a link to your log on [Flight Log Review](https://logs.px4.io/).
