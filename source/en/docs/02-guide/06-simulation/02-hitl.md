# Hardware-In-The-Loop Simulation (HITL)

## Introduction

Unlike software-in-the-loop simulation, hardware-in-the-loop simulation still runs on real autopilot hardware, so real hardware peripherals can be connected, such as receivers, and actuators like motors and servos or other hardware can be driven normally.

## Flashing the Simulation Firmware

Download the hardware-in-the-loop simulation firmware from [Downloads](../../../download/) (the firmware file name generally ends with HITL).

Connect the autopilot and the debug board, open the ground control station software, follow the flashing procedure, connect debug board `FCS-USB` to the computer, and flash the firmware to the autopilot.

## Flight Simulation

Follow the real-aircraft communication connection and operating procedures to perform simulated flight.
