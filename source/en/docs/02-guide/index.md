# NextPilot Tutorials

NextPilot is a feature-rich, highly extensible, stable and reliable advanced autopilot, **built on the domestic RT-Thread operating system and supporting fully domestic hardware customization**. It supports multirotor, fixed-wing and VTOL UAVs, **supports Simulink model-based design**, and can be readily applied in education, research and industry.

This guide covers every stage from assembly, configuration and flight operations to data analysis.

## NextPilot Highlights

- Autonomous takeoff and landing on shipborne moving platforms
- Vision-assisted takeoff and landing
- High-precision accurate airdrop
- Swarm multi-vehicle formation control
- High-precision industrial-grade IMU, **no external damping required**
- Ground control station with integrated virtual flight simulation
- Ground control station with logging and replay
- Ground control station with 3D mission planning

## Try NextPilot

No hardware required — the NextPilot-Ground-Control station integrates [virtual flight simulation](06-simulation/01-sitl.md). Create a virtual vehicle link in the ground control station and you can start flying right away.
