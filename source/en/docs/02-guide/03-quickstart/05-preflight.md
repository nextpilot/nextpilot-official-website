# Preflight Check

Before a full flight, a preflight check must be performed to ensure flight safety.

Click the "Preflight Check" button in the General section of the left sidebar of the ground station to enter the operation screen. The preflight check mainly covers:

1. Power management check;

2. Integrated navigation check;

3. Joystick input check;

4. Radio control check;

5. Control output check;

6. Propulsion engine check;

7. Mission check.

## Checking the Firmware Version

Go to Preflight Check -> Basic Information Check to view the firmware version information, including the flight control firmware, internal INS firmware and external INS firmware versions.
