# Airframes

UAV actuators generally include servos, ESCs and motors, engines, etc., and the drive signals are generally PWM. The autopilot provides a total of 16 PWM output channels, which must be connected according to the vehicle type.

The airframes corresponding to each vehicle type are described in [Airframe Setup](../04-config/01-basic-setup.md#airframe-setup).

In the tables below, refer to [Flight Controller Interfaces](../../../product/autopilot/np-fcc-h05.md#pin-definition) for the wiring order of the airframe pin definitions.
