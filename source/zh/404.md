# 404

## 页面未找到

抱歉，您访问的页面不存在。可能已被移除、更名或暂时不可用。

- 检查 URL 是否拼写正确
- 返回 [首页](/) 继续浏览
- 查看 [文档](/docs/manual/) 获取帮助

    // 不做自动跳转，展示 404 页让用户手动选择
  }
})
</script>
